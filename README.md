# Wingmen Vision

Surveillance, OSINT, and threat-intelligence dashboard for security operations.

## Stack
- React 19 + TypeScript + Vite
- Tailwind CSS 4
- Supabase (live endpoints via backend/lib/live_api.ts)
- Mock data removed; real DB schemas in backend/schemas/

## Backend Services
- event_pipeline.ts
- report_generator.ts
- threat_detection.ts
- supabase_client.ts
